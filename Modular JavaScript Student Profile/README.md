1. What is the difference between a function parameter and a function argument?
> A function parameter holds a variable to receive data, while a function argument is the actual value you pass into the function when you call it.

2. How does `this` keyword allow an object method to reference properties within the same object?
> The keyword (this) points to the object so that it can access or change its own properties.

3. Why is modularizing code using `import` and `export` useful in modern JavaScript decelopment?

4. Why is it important to run `git pull origin main` before creating new folders and pushing commits to your main repository?
> Running git pull origin main first updates your local project with the latest changes or updates from the online repository in GitHub so that it matches the work. This will also prevent from accidentally overwriting new files or conflicts merging.
